# Security and privacy

- The included feedback is invented and contains no real respondent details.
- Use environment variables or a managed secret store; never commit credentials.
- Do not upload sensitive real documents to public repositories, logs, or CI.
- Scrub personal information before sending text to NLP APIs and assess data residency requirements.
- Apply role-based permissions, encryption, and retention rules to stored feedback.
- Evaluate sentiment bias and avoid making individual-level high-stakes decisions based solely on scores.
